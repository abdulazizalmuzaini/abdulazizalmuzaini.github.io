# Massachusetts Education Data Dashboard  
 
In this project, I used the 2017 State of Massachusetts education data. The project is part of the Data Analytics Accelerator Program led by Avery Smith.  

The dashboard was created using Tableau. The total number of schools included in the dataset was 1,861, and the number of students was 953,748. 
The analysis aims to answer these key questions:  
What are the top math schools?

Which schools are struggling the most?  

Does the average class size affect college admissions? 

I have found that, using a scatter plot, the higher the average class size is, the higher the percentage of students attending college. However, with an r-square of only 0.19 (which is a very weak indicator), we cannot assume that this result is true. There could be other variables affecting college admissions.  

### These schools have the lowest graduated students' percentage: 

Springfield Public Day High School (8.7%); 

Boston Day and Evening Academy Charter School (9.8%); 

Whaling City Junior/Senior High School (11.4%); 

Springfield High School (11.6%); 

Phoenix Academy Lawrence (13%). 

### Only four districts out of 100 have passed the 50% threshold on the standardized 4th Grade math test.

Community Day Charter Public School – R. Kingman Webster (Average score: 61%); 

Community Day Charter Public School – Prospect (average: 58%); 

Community Day Charter Public School – Gateway (average= 57%); 

Orleans (average=50%).
